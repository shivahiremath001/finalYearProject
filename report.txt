SECTION 1 — PROJECT OVERVIEW
────────────────────────────────────────────────────────────────────────────────

R3P is a final-year project that provides a centralized dashboard for monitoring
the security posture of Windows machines against ransomware threats. It consists
of three components:

  1. Backend   — FastAPI server (Python) with SQLite database
  2. Frontend  — React dashboard (Vite) for admin monitoring
  3. Agent     — Windows collector (collector.py / R3P_Agent.exe) that runs on
                 monitored machines and pushes telemetry to the server

Admin credentials (default):
  Username : admin
  Password : R3P-Admin-2025!

SECTION 3 — HOW TO RUN (EVERY SESSION)
────────────────────────────────────────────────────────────────────────────────

Open 3 PowerShell terminals:

  Terminal 1 — Backend:
    cd backend
    .\venv\Scripts\activate
    uvicorn main:app --host 0.0.0.0 --port 8000 --reload

  Terminal 2 — ngrok tunnel:
    ngrok http --url=sleep-abnormal-sputter.ngrok-free.dev 8000

  Terminal 3 — Frontend:
    cd frontend
    npm run dev
    (open http://localhost:5173)

  On monitored machine:
    Run dist\R3P_Agent.exe
    (ensure r3p_server.txt is in same folder as the .exe)

  Sanity check:
    https://sleep-abnormal-sputter.ngrok-free.dev/health → {"status":"ok"}
    https://sleep-abnormal-sputter.ngrok-free.dev/docs   → Swagger UI

  NOTE: JWT tokens expire after 8 hours. If dashboard shows no data,
  log out and log back in to get a fresh token.

SECTION 5 — KNOWN ISSUES & NOTES
────────────────────────────────────────────────────────────────────────────────

  - JWT tokens expire after 8 hours. Users must re-login after expiry.
    The dashboard will show 403 on WebSocket if token is stale.

  - ngrok free tier: WebSocket works but requires the
    "ngrok-skip-browser-warning" header/query param (already implemented).

  - The static ngrok domain (sleep-abnormal-sputter.ngrok-free.dev) is
    session-bound — ngrok must be running for the agent and dashboard
    to communicate with the backend.

  - The agent .exe reads r3p_server.txt from the same folder as the .exe.
    Both files must always be together when deploying to another machine.

  - collector.py must be run with admin privileges (UAC elevation) for
    some checks like BitLocker, LSASS, and driver checks to return
    accurate results.
